# Quick start for families

1. Install and start the service using [INSTALLATION.md](INSTALLATION.md).
2. On the TV, open `http://127.0.0.1:8765/` (or the appliance's local IP from another device).
3. Enter the parent PIN set securely during installation, then use the parent page to configure categories, limits, and optional features.
4. Start an activity on the TV. The current activities include Avocado and Memory Chain; answers are entered manually. There is no microphone capture or speech recognition.
5. Optional: enable local eSpeak NG speech output if installed. It does not send audio to a cloud service.
6. Optional: upload a parent-provided MP4 or WebM through the parent controls for local playback. No downloader is included.

Ask Rocky is a pretend, text/activity experience; no voice recording or retention is involved. Use a private home network and keep the parent PIN private.
