# Parent guide

## Set up and secure

Set a unique 6–12 digit PIN in the installer's hidden prompts and keep it private. Then open `/parent` on the appliance to sign in. Use a trusted private LAN only. Parent sign-in controls settings, category availability, nicknames, history, and the local video library. If the PIN is forgotten, use the locally run reset script described in [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Activities

The app currently provides Avocado (category-based turn-taking and answer matching) and Memory Chain (recall a growing sequence). Child answers are entered manually; no microphone or speech recognition is available. Adjust session/break settings and activity options in parent controls.

Ask Rocky is a pretend activity simulation. It does not connect to Alexa and does not record or retain audio. The bundled Rocky character art is original helper artwork and is not Paw Patrol artwork.

## Learning library

Open **Learning library** on your phone. Enable activities one by one, then tap **Play on TV**. The starter set includes **Matching pairs** (eight cards/four pairs), counting one to five stars, colour matching and shape matching. All run offline inside the TV interface and start disabled. Enable switches are saved on the device.

The child can answer and flip cards but cannot launch, restart, switch or leave these activities. A completed board stays on screen. Use **Return TV home**, **Restart current game**, or another activity's **Play on TV** button on your phone. Disabling the current activity stops it. Pause and Lock preserve the board; Resume or Unlock returns to it. Automatic session breaks still apply; use Resume to continue or Home to end. Games do not resume after a service restart.

These are original browser activities inspired by educational suites such as [GCompris](https://gcompris.net/), not GCompris code, artwork or the full GCompris library. Nothing from GCompris is downloaded or launched.

## Videos and family media

Parents can upload MP4 or WebM files, with a maximum request size of 256 MiB. The app verifies the extension and a basic file signature, then stores the file locally. The parent UI can manage playback/library entries. There is no YouTube downloader; obtain and upload media lawfully. Use browser-compatible encoding and supervise playback.

## Data

Settings and local media persist on the device. Activity history is optional. See [PRIVACY.md](PRIVACY.md) and [SECURITY.md](SECURITY.md). Keep regular protected backups and test restoration using a separate copy/device when possible.
